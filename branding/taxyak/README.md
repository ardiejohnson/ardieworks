# TaxYak — brand assets

Logo and mascot for **TaxYak**, a tax prep app. The concept: a yak that *yaks* —
it talks you through your taxes in plain language, so the mascot lives in a
speech bubble.

## Files

| File | What it is |
|------|-----------|
| `taxyak-icon.svg` | App icon / favicon — yak face in a teal speech bubble |
| `taxyak-mascot.svg` | The yak face alone (natural browns), for in-app illustration |
| `taxyak-logo.svg` | Horizontal lockup: icon + "TaxYak" wordmark. The wordmark uses Bricolage Grotesque via a Google Fonts `@import`, so it needs to be online to render with the right font (falls back to system sans otherwise). |
| `canvas/` | Source artboards for the design canvas (three explored directions) |

## Palette (Direction A — "Chatty Yak")

- Brand teal `#0E6B5C`
- Ink `#26221D`
- Cream `#F6F3EC`
- Horn gold `#F2C94C` (mascot-alone version uses deeper `#C9A227`)
- Straw `#E2D5BE`

## Type

Wordmark: **Bricolage Grotesque** ExtraBold (Google Fonts), letter-spacing −0.02em.
"Tax" in ink, "Yak" in brand teal. Tagline: *Taxes, talked through.*

## Unchosen sketch directions (kept in `canvas/`)

- **B — Sturdy Yak**: side-profile yak on a forest-green badge, slab type. More "established firm."
- **C — Summit Yak**: single-line minimal yak, indigo. Calm and premium.
